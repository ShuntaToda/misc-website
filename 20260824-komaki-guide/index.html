ウェブデザイン職種とは

課題は当日まで秘密。仕様書とデザインを見て、制限時間内にウェブサイトを作る。

競技の流れ

モジュール（種目）

全国大会は2日間で4つほどのモジュールをこなす。内容は年によって変わる。

M1SPEED

スピードテスト

小さな課題をたくさん。速さと正確さ。

M2BACKEND

バックエンド / API・CMS開発

保存・ログインなど「裏側」を作る。

M3FRONTEND

デザインカンプから静的サイト構築

デザイン画像をそっくりページにする。

M4APP

インタラクティブなアプリ

ゲームやツールなど「動き」のあるもの。

評価ポイント

仕様どおりに動くか

書かれた機能が全部あり、正しく動く？

デザインどおりか

色・サイズ・余白が見本と同じ？ スマホでもくずれない？

コードの品質

HTMLの書き方が正しく、誰が読んでもわかる？

アクセシビリティ

読み上げソフトやキーボードだけでも使える？

使う道具 — プロと同じ3つ

エディタ（VS Code など） ブラウザ（Chrome など） DevTools（ブラウザの開発者ツール）

0:25 – 0:35

ウェブサイトの仕組み

どんなサイトも3つの言葉でできている。骨組み・服・動き。

ブラウザとサーバーの往復

3つの言葉の役割

HTML
骨組み・中身

「何があるか」を書く。

  • タグ … <p>…</p> のように囲んで印をつける
  • 要素 … タグで囲まれたひとかたまり
  • 属性 … <img src="…"> のようにタグに付ける追加情報
CSS
見た目

「どう見せるか」を書く。

  • セレクタ … どこに当てるか（button、.card、#title）
  • プロパティ … 何を変えるか（color、font-size）
  • 値 … どう変えるか（red、20px）

書き方: セレクタ { プロパティ: 値; }

JavaScript
動き

「何が起きるか」を書く。

  • 変数 … 数や文字を入れておく箱（let count = 0）
  • 関数 … まとめた処理（function …）
  • イベント … 「押したとき」などのきっかけ（click）

要素を取って、きっかけで、変える。

3つを積み重ねると

上がコード、下が表示。3枚目のボタンは本当に押せる。

DevTools で好きなサイトを書きかえる

DevTools（開発者ツール）を開くと、どんなサイトの HTML と CSS も見えて、その場で書きかえられる。

開き方: F12 または Ctrl+Shift+I ／ Mac は ⌘+option+I ／ ページを右クリック →「検証」
  1. 1

    開く — 右クリック →「検証」

    好きなサイト（例: 技能五輪全国大会ページ）で右クリック → いちばん下の「検証」。

    やってみよう: 学校のホームページで右クリック →「検証」。

  2. 2

    見る — 上が HTML、下が CSS

    上の Elements が HTML、下の Styles が CSS。左上の矢印アイコン → ページの文字をクリックで、その行が選ばれる。

    やってみよう: 見出しをクリックして <h1> を見つける。

  3. 3

    書きかえる — ダブルクリックして入力

    Elements の文字をダブルクリック → 書きかえて Enter。Styles の color の値を red にすると色も変わる。

    やってみよう: 見出しを自分の名前に、背景を red に。

  4. 4

    戻す — こわれないので安心

    変わるのは自分の画面の中だけ。

    F5 ですぐ元に戻る。

    選手はこの DevTools で、見本と1ピクセルのズレまで合わせる。

    やってみよう: F5 で元に戻るのを確認。

ハンズオン②: AIで開発体験

AIにコードを書いてもらう。ログイン不要の duck.ai を使う。「書いてもらう → 貼る → 直してもらう」のくり返し。

duck.ai を開く（新しいタブ）

手順

  • duck.ai で「Start Chat」
  • 下のプロンプトを「コピー」→ 貼って送信
  • 出てきたコードを「Copy」→ エディタの「自由」HTMLタブに貼る
  • 動かなければ、コンソールの赤い文字をAIに送って「直して」

プロンプト例

PROMPT 1 — まずはこれ

HTML・CSS・JavaScript を1つのHTMLファイルにまとめて、「おみくじアプリ」を作ってください。
条件:
- ボタンを押すと「大吉」「中吉」「小吉」「凶」のどれかがランダムで大きく表示される
- 結果によって背景色が変わる
- スマホでも見やすいデザイン
- 外部ライブラリやCDNは使わない
- コードは1つのコードブロックにまとめて出してください

PROMPT 2 — 直してもらう

さっきのコードを次のように変えてください。変更後のコード全体をもう一度出してください。
- ボタンを押した回数を表示する
- 結果が出るときにふわっとアニメーションする
- 全体の色をダーク系にする

PROMPT 3 — エラーを直してもらう

このコードを動かしたら、次のエラーが出ました。原因と直し方を教えて、直したコード全体を出してください。
エラー: （ここにコンソールの赤い文字を貼る）
⚠

個人情報は送らない。AIはまちがう。何を作るか決めて、合っているか確かめるのは人の仕事。

解説ストーリーの種づくり

12月に見学者へ話す「自分の言葉」を作る。書いたら3〜4人で発表。

小学生に30秒で説明するなら？

今日いちばん「へぇ」と思ったことは？

見学者に出すクイズを1つ（答えも）

クイズ案

  • Q. HTMLを全部消すとどうなる？

    A. 真っ白。中身がないので何も表示されない。

  • Q. CSSを全部消すとどうなる？

    A. 文字と画像だけの「素」のページになる。

  • Q. JavaScriptを全部消すとどうなる？

    A. 見た目はそのまま。ボタンを押しても何も起きない。

  • Q. 課題はいつわかる？

    A. 当日。だから「何が来ても作れる力」を練習する。

発表のしかた

  • 1人ずつ「30秒説明」（時間をはかる）
  • 聞いた人は「わかりやすかったところ」を1つ言う
  • いちばん伝わる説明を1つ選んで全体に発表
