ウェブデザイン職種とは

課題は当日まで秘密。配られた仕様書とデザインを見て、制限時間内にウェブサイトやウェブアプリを作ります。 デザインを見る力・コードを書く力・スピード、全部が必要です。

競技の流れ（1つのモジュール）

  • 課題が配られる — 仕様書（文章）とデザインカンプ（完成イメージの画像）。読んで、やることを整理する
  • 作る — エディタでコードを書く。ブラウザで確認しながら進める。制限時間は1〜3時間くらい
  • 提出 — 時間になったら手を止める。未完成でも提出
  • 採点 — 審査員が「仕様どおりか」「デザインどおりか」「コードがきれいか」を見る

モジュール（全国大会）

全国大会は2日間で、いくつかの「モジュール」（種目）を順番にこなします。内容は年によって変わりますが、だいたいこんな種類です。

M1SPEED

スピードテスト

短い時間で小さな課題をたくさん。HTML/CSS/JS の基本を、どれだけ速く正確にできるか。

M2BACKEND

バックエンド / API・CMS開発

データを保存したり、ログインしたりする「裏側」を作る。データベースやAPIを設計する。

M3FRONTEND

デザインカンプから静的サイト構築

渡されたデザイン画像をそっくりそのまま、ブラウザで動くページにする。スマホでもくずれないように。

M4APP

インタラクティブなアプリ

JavaScriptを使ったゲームやツール。押す・動く・保存する、など「動き」のあるもの。

評価ポイント

仕様どおりに動くか

ボタンを押したら正しく動く？ 入力チェックは？ 書かれた機能が全部ある？

デザインどおりか

色・サイズ・余白・フォントが見本と同じ？ 画面幅を変えてもくずれない？

コードの品質

HTMLの書き方が正しい？ 名前がわかりやすい？ 誰が読んでも理解できる？

アクセシビリティ

目の不自由な人が使う読み上げソフトでも使える？ キーボードだけで操作できる？

Web標準への準拠

ブラウザのルール（標準）どおりに書いている？ どのブラウザでも動く？

0:25 – 0:35

ウェブサイトの仕組み

どんなウェブサイトも、たった3つの言葉でできています。人にたとえると 骨組み・服・動き。

ブラウザとサーバーの往復

3つの言葉の役割

HTML
骨組み・中身

見出し、文章、画像、ボタン。「何があるか」を書く。

  • タグ … <p>…</p> のように < > で囲んで「ここは段落」と印をつける。開始タグと終了タグ
  • 要素 … タグで囲まれたひとかたまり
  • 属性 … <img src="…"> のようにタグに付ける追加情報
CSS
見た目

色、大きさ、ならび方、角丸、影。「どう見せるか」を書く。

  • セレクタ … どこに当てるか（button、.card、#title）
  • プロパティ … 何を変えるか（color、font-size）
  • 値 … どう変えるか（red、20px）

書き方: セレクタ { プロパティ: 値; }

JavaScript
動き

押したら変わる、数える、保存する。「何が起きるか」を書く。

  • 変数 … 数や文字を入れておく箱（let count = 0）
  • 関数 … まとめた処理（function …）
  • イベント … 「押したとき」などのきっかけ（click）

要素を取って、きっかけで、変える。

同じHTMLでも、CSSがあるとこう変わる

この3つの言葉を実際のコードで積み重ねるとこうなる。左がコード、右がブラウザの表示。3枚目のボタンは本当に押せる。

DevTools で好きなサイトを書きかえてみよう

どんなサイトでも「中身」をのぞけます。ブラウザの DevTools（開発者ツール） を開くと、HTMLとCSSが見えて、その場で書きかえられます（自分の画面の中だけ。元のサイトは変わらない）。

開き方: F12 または Ctrl+Shift+I ／ Mac は ⌘+option+I ／ ページを右クリック →「検証」
  1. 1

    開く — 右クリック →「検証」

    好きなサイトを開く（例: JAVADA 技能五輪全国大会ページ）。ページの上で右クリックして、メニューのいちばん下の「検証」を押す。F12 でも同じ。

    やってみよう: 学校のホームページを開いて、右クリック →「検証」。

  2. 2

    見る — 上が HTML、下が CSS

    右側に DevTools が開く。上の Elements がそのページの HTML、下の Styles が選んだ要素の CSS。左上の矢印アイコンを押してからページの文字をクリックすると、その行が青くハイライトされる。

    やってみよう: 矢印アイコン → ページの見出しをクリック → Elements で <h1> が光るのを確認。

  3. 3

    書きかえる — ダブルクリックして入力

    Elements の文字をダブルクリックすると入力できる。好きな文字にして Enter → ページの文字が変わる！ Styles の color や background-color の値をクリックして red などに変えると見た目も変わる。

    やってみよう: 見出しを自分の名前に変える／Styles で背景色を red にする。

  4. 4

    戻す — こわれないので安心

    変わるのは自分の画面の中だけ。

    元のサイト（サーバーにあるファイル）は1文字も変わらない。他の人の画面にも出ない。

    F5（再読み込み）ですぐ元に戻る。

    だから、どんどんさわってOK。選手はこの DevTools で、見本と1ピクセルのズレまで合わせていく。

    やってみよう: 書きかえたあとに F5 → 元に戻るのを確認。

💬

解説で使えるひとこと:「選手はこのDevToolsを使って、1ピクセルのズレまで見本と合わせていきます。」

1:20 – 1:45

ハンズオン②: AIで開発体験

今度はAIにコードを書いてもらいます。ログイン不要で使える duck.ai を使います。 「AIが書く → エディタに貼る → 動かす → 直してもらう」をくり返すのが、今のプロの開発に近いやり方。

duck.ai を開く（新しいタブ）

手順

  • duck.ai を開く。「Start Chat」でチャット画面に（モデルはどれでもOK）
  • 下のプロンプト例を「コピー」→ duck.ai に貼って送信
  • AIが出したコードの右上「Copy」を押す → エディタ（右下のボタンか E）の「自由」ステップ、HTMLタブに貼る
  • 右に表示される。動かなければ、コンソールの赤い文字をAIに送って「直して」
  • 気に入るまで「ここを変えて」をくり返す。どんどん注文しよう

プロンプト例（コピーして使おう）

PROMPT 1 — まずはこれ

HTML・CSS・JavaScript を1つのHTMLファイルにまとめて、「おみくじアプリ」を作ってください。
条件:
- ボタンを押すと「大吉」「中吉」「小吉」「凶」のどれかがランダムで大きく表示される
- 結果によって背景色が変わる
- スマホでも見やすいデザイン
- 外部ライブラリやCDNは使わない
- コードは1つのコードブロックにまとめて出してください

PROMPT 2 — 直してもらう

さっきのコードを次のように変えてください。変更後のコード全体をもう一度出してください。
- ボタンを押した回数を表示する
- 結果が出るときにふわっとアニメーションする
- 全体の色をダーク系にする

PROMPT 3 — エラーを直してもらう

このコードを動かしたら、次のエラーが出ました。原因と直し方を教えて、直したコード全体を出してください。
エラー: （ここにコンソールの赤い文字を貼る）

PROMPT 4 — 自由課題のアイデア

高校生が5分で遊べる、ブラウザで動く小さなゲームを1つ提案して、HTML・CSS・JavaScript を1つのファイルにまとめたコードを出してください。外部ライブラリは使わないでください。
⚠

個人情報を入れない。名前・住所・学校名・友だちのことなどはAIに送らない。

⚠

AIの出力はまちがうこともある。動かない・変なときは「ここがおかしい」と伝えて直してもらう。最後に判断するのは人間。

💬

解説で使えるひとこと:「AIはコードを出してくれるけど、“何を作るか決める”“合っているか確かめる”のは人の仕事。選手はその力がすごく高い人たちです。」

解説ストーリーの種づくり

12月の会場で、見学に来た小学生・中学生に話すときの「自分の言葉」を作ります。下の欄に書いてOK（このPCに保存されます）。書いたら3〜4人で発表。

今日やった中で、いちばん「へぇ」と思ったことは？（それが一番伝わる話になる）

見学者に出すクイズを1つ考えよう（答えも）

選手のすごさを伝えるひとこと

クイズ案（そのまま使ってOK）

  • Q. HTMLを全部消すとどうなる？

    A. 真っ白。中身がないので何も表示されない。CSSもJSも効かせる相手がいない。

  • Q. CSSを全部消すとどうなる？

    A. 文字と画像だけの白黒ページになる。内容は全部残っているけど、見た目が「素」になる。DevToolsで実演できる。

  • Q. JavaScriptを全部消すとどうなる？

    A. 見た目はそのまま。でもボタンを押しても何も起きない。動きが全部止まる。

  • Q. 選手は競技で何を使っている？

    A. エディタ・ブラウザ・DevTools。特別な機械はなく、プロと同じ道具。

  • Q. 課題はいつわかる？

    A. 当日。だから「何が来ても作れる力」を練習する。

  • Q. 1つの課題の時間はどれくらい？

    A. 全国大会は1つ1〜3時間くらい。国際大会は4日間で合計15時間以上。
